# Getting started

Choose the guide that matches the supported product mapping you are using:

| Platform | Supported interface | Guide |
| --- | --- | --- |
| Windows | PowerShell 7 | [Windows with PowerShell](windows-powershell.md) |
| Linux | Bash | [Linux and macOS with Bash](linux-macos-bash.md) |
| macOS | Bash | [Linux and macOS with Bash](linux-macos-bash.md) |

PowerShell on Linux/macOS and Bash on Windows are not supported product combinations.

Each guide contains the exact syntax for stable bootstrap and the normal Install, List, Verify, Remove, and direct-SDK workflows. Shared command behavior is documented once in the [command reference](../commands/README.md).

For the complete platform/runtime assumptions, see [Cross-platform support](../concepts/cross-platform-support.md).
